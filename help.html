HandyMon

A local-network web dashboard for controlling this PC — display, audio, fans, processes, and more — from a phone or any browser on the LAN.

Opening the dashboard

On this PC: open a browser and go to http://localhost:44558 (or whichever port you chose during setup).

From your phone or another device: right-click the HandyMon icon in the system tray (near the clock — click the ^ arrow if it's hidden) and choose Pair new device. Scan the QR code with your phone's camera to pair it.

HandyMon never leaves your local network — there's no cloud account and nothing is sent externally.

The tray icon

HandyMon runs in the background with an icon in the system tray. Left-click it (or right-click for the menu) for:

  • Open UI — opens the dashboard in your default browser
  • Pair new device — shows a QR code for pairing a phone
  • Open config folder — opens %LOCALAPPDATA%\HandyMon, where settings, paired devices, and logs live
  • Quit — fully stops HandyMon

Starting HandyMon

HandyMon starts automatically at login (via a Windows Scheduled Task named HandyMon). If you didn't launch it right after installing, you don't need to log out and back in — use the Start HandyMon shortcut in the Start Menu instead.

Stopping / uninstalling

To stop HandyMon without uninstalling, use Quit from the tray icon menu. It'll start again at your next login.

To remove it entirely, use Uninstall HandyMon from the Start Menu, or Windows Settings → Apps.

Setting up external tools

Nothing below is required — HandyMon works without any of them, just with less info/control in that one area. Each is independent; set up only what you actually use. Every path here is configurable in Settings if your install location is different from the default.

RTSS (RivaTuner Statistics Server) Framerate limiting + overlay

Search for "RivaTuner Statistics Server" (it's also bundled with MSI Afterburner, but installs standalone too). Default install location: C:\Program Files (x86)\RivaTuner Statistics Server.

  • Set the install folder in Settings → Tool Paths → RTSS Installation Folder, then hit Test.
  • HandyMon starts/stops RTSS itself directly — no separate scheduled task or startup shortcut needed.
  • If the Gaming tab still says "RTSS not found" after installing, double-check the folder path — it should contain RTSS.exe directly, not a subfolder.

FanControl Fan profile switching

Download from the FanControl GitHub releases page. Default install location: C:\Program Files (x86)\FanControl\.

  • Set the install folder in Settings → Tool Paths → FanControl Folder, then hit Test.
  • Important: FanControl needs to have been run at least once, with at least one profile configured inside FanControl itself, before HandyMon can list any profiles — it reads FanControl's own cache file, which doesn't exist until FanControl has started.

Process Lasso Per-process CPU/priority rules

Download from bitsum.com. Default config location: C:\ProgramData\ProcessLasso.

  • Set the folder in Settings → Tool Paths → Process Lasso Config Folder, then hit Test.
  • Like FanControl, it needs to have been installed and run at least once — its config file is only created after first launch.
  • If you just installed it or changed this path, restart HandyMon (Quit from the tray, then Start HandyMon from the Start Menu) — this path is only read once at startup.

LibreHardwareMonitor + PawnIO Temps, power, clocks, fan RPM

Performance usage (CPU/GPU %, RAM) works with no setup at all. Hardware sensors need LibreHardwareMonitor running with its web server enabled, plus the PawnIO driver for CPU/motherboard readings specifically.

  • If you installed with the "LibreHardwareMonitor + PawnIO driver" option checked (checked by default unless the installer found you already had LibreHardwareMonitor), you don't need to do anything — a dedicated copy is bundled, pre-configured, and starts automatically with HandyMon on its own port (separate from any LibreHardwareMonitor you might already run yourself, so the two don't collide). Just confirm it in Settings → Performance Monitoring with Test.
  • Setting it up yourself instead — portable download from the LibreHardwareMonitor GitHub releases page (no installer, just unzip). Run it elevated (right-click → Run as administrator), then enable Options → Remote Web Server. Default port 8085, configurable in Settings → Performance Monitoring (use Test to confirm HandyMon can reach it). It needs to stay running in the background — doesn't need to stay in focus, just running.
  • PawnIO — required for CPU package and motherboard sensors specifically (temps/power/clocks); GPU/disk/network sensors work without it. Bundled automatically alongside LibreHardwareMonitor above, or download separately from pawnio.eu.

PresentMon In-game FPS / frametimes

If you installed with the "PresentMon" option checked (checked by default unless the installer found CapFrameX already), a known-compatible copy is bundled and used automatically — nothing to configure. Otherwise, HandyMon auto-detects a PresentMon binary from CapFrameX or an RTSS install if you have either, or you can point Settings → Performance Monitoring → PresentMon Executable at one directly.

  • FPS data only appears while a game is actually presenting frames — desktop idle correctly shows nothing.
  • If Test stays red, click Show diagnostic right below it — it runs a fresh probe and reports exactly what happened (crashed, timed out, or working) rather than a generic failure.

Troubleshooting

  • Windows Firewall prompt on first run — allow access on Private networks so other devices on your LAN can reach the dashboard.
  • Can't reach it from your phone — make sure the phone is on the same Wi-Fi network as this PC, and that the firewall prompt above was allowed.
  • Port already in use — you can change the port anytime by editing port in %LOCALAPPDATA%\HandyMon\config.json, then restarting HandyMon (Quit from the tray, then Start HandyMon from the Start Menu).
  • Some features are greyed out — several features (fan control, Process Lasso, RTSS, LibreHardwareMonitor) rely on optional external tools. See Setting up external tools above.
